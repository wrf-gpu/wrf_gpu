original-WRF inputs. The release restores WRF plume cloud-base geometry,
cloud and mass-flux Sm/Sh floors, upward mass-flux TKE production using the
previous mixing length, the `elh` energy-budget term, surface density from
actual PSFC, and condensation that carries cloud water from the level below
with a **per-column** `|ΔQC| < 1e-6` exit. WRF REAL constants, including
P608 = 0.60836, replace rounded port literals. The smallest sufficient matched
set was plume geometry + Sm/Sh floors + condensation; the complete release
set passed step-one and step-two checks on d01 and d02.

- **D1:** Kain–Fritsch tendencies use WRF mass coupling and their held-rate
  lifetime through RK; precipitation is counted once. KF uses hydrostatic
  pressure and preserves the no-trigger NCA sentinel.
- **D2:** PBL water and moist-theta tendencies follow WRF conversion,
  mass-coupling and addition order, including the joint MYNN+KF root path.
- **D3:** held radiation heating enters every RK stage in WRF order, with
  the original REAL multiply/divide sequence retained.

The composed source also includes WRF REAL constants for Thompson, RRTMG,
KF, PHY_PREP and writer diagnostics; fractional Julian radiation timing;
