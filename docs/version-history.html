Version History

A release-by-release summary. stability > identity is the top priority, but a proven correctness repair may intentionally change results and require a rebaseline, as v0.23.4 does. Full per-release notes live in the release_notes/ folder of the repository.

Reading the "default numerics" column

Byte-identical = same compiled program, bit-for-bit output vs the prior release. Numerically equivalent = value-preserving change to the program (proven CPU bit-identical + within the GPU autotune floor). New capability is almost always opt-in and inert by default.

v0.23.4 candidate — nine-nest correctness closure, d03 performance regression understood¶

VersionHighlightsDefault numerics
v0.23.4 candidate (prepared)Correctness-complete; d03 performance regression measured, root-caused, investigation closed. Closes the SP2 mass-flux seam, S2 boundary retention, V/V10 moist/scalar ordering, and Thompson late-Ni balance in one linear chain. Ships as a known, understood limitation.
