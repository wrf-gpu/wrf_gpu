Version History

A release-by-release summary. Because stability > identity is the top priority, the default (fp64, no-env) forecast stays byte-identical or numerically equivalent across releases unless a change is proven value-preserving. Full per-release notes live in the release_notes/ folder of the repository.

Reading the "default numerics" column

Byte-identical = same compiled program, bit-for-bit output vs the prior release. Numerically equivalent = value-preserving change to the program (proven CPU bit-identical + within the GPU autotune floor). New capability is almost always opt-in and inert by default.
