Configuration boundaries and current findings

Supported scope

Use the wired physics menu and named namelist checks. Selected original-CPU regional comparisons cover 24/72 hours; broader seasonal observational equivalence is not claimed. The current v0.3.3 W3 candidate still needs its affected frozen gates.

Terrain and geometry

Validate a new geometry and forcing against its own original CPU reference; the shipped Alpine example does not establish arbitrary terrain or glacier physics. Dedicated Noah-MP glacier evolution is unported.

Initial and boundary forcing

Use consistent prepared WRF inputs and lateral boundaries for regional forecasts. Support for an option is not a blanket stability guarantee outside the measured cases.

Memory and compilation

Use the case-sized memory plan and measured host/GPU headroom. C-auto precedence and cold fallback are described under running. Source/geometry/target changes can compile anew. Small launch-limited grids and large measured regional workloads have different performance; dated benchmarks include substantial single-card gains.

Current source-specific findings

Read KNOWN_ISSUES and validation. W2 0115 has recorded annex-real wind failures and systematic station WS10 damage; W2 Monica has a hard compiled-stack failure. W3 composes the reviewed shortwave correction and bitwise layout fixes, then applies affected gates once. Old passes, controls or trace judgements are not relabelled as W3.

Earlier findings are history

Earlier v0.23.x and v0.3.0 limitations are source-dated in version history. Do not treat the old 104-field default, fixed native sound count, ignored advection controls or pending v0.3.1 fixes as current capabilities. Full history is default; native controls and SST support have explicit scope on their corresponding pages.

Beyond the validated configuration

MPI/multi-GPU domain decomposition, moving nests, coupled chemistry/fire/hydrology and universal scheme pairing are outside the present operational scope. Checkpoint/resume covers native single-domain d01 and nested runs, not CPU-WRF replay; WRF wrfrst interchange is not supported. Benchmark and extrapolation assumptions are kept on performance.

Future v0.3.4 roadmap

Standalone restart, actual cluster interfaces qualified through simulation, grid FDDA first, then RUC/NSSL and further schemes. Chem/Fire are separate program tracks. This is a future plan, not current support or v0.3.3 closure; real-cluster performance is unmeasured. Ordered public roadmap and qualifications.
